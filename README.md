# QGIS
These QGIS primarily manipulate mobile network shapefiles (.shp and their associated .dbf/prj/.shx) and/or UE measurement point data. Pretty self explanatory, although detailed notes will be given with each script, otherwise you'll make a mess.
Use them ONLY within QGIS.
They work best with UK data as you need certain ONS (office of National Statistics)/Ordnance Survery data overlays (land usage/output area etc - dunno if other countries have/use the same methodology). I dont upload that here - I'll put the correct links in.
Also, you'll need the QuickOSM plugin - it's AWESOME
